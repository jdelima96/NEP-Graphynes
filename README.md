# Neuroevolution Potential (NEP) for Hexagonal and Rectangular $\gamma$-Graphynes

This repository contains the reference datasets (`train.xyz` and `test.xyz`) and the corresponding trained Neuroevolution Potential (NEP) models (`nep.txt`) developed in the study:

> **Superior thermal conductivity and enhanced mechanical stiffness in rectangular $\gamma$-graphyne revealed by machine learning interatomic potentials**

## 📁 Repository Structure

The data and model files are organized into two distinct directories based on the material structure:
* `gyg/` - Reference configurations and trained NEP model for pristine/hexagonal $\gamma$-graphyne.
* `rgyg/` - Reference configurations and trained NEP model for rectangular $\gamma$-graphyne.

Each directory contains the respective training (`train.xyz`), testing (`test.xyz`), and optimized NEP potential (`nep.txt`) files compatible with the GPUMD package.
